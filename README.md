# 被代办人记在哪里：家庭服务时间账

这里保存被代办人记在哪里：家庭服务时间账工作所用的匿名合成记录。文件不包含分析结果或居民个人资料。

## 资料

`samples/` 中每个文件都是独立的 UTF-8 JSON 文档：`frame`、`diary`、`events`、`options`、`transport`、`policy`。日期是当地日历日期。空值表示没有对应观测或状态资料，不是数值零。

日志时间为当地分钟；超出 1439 代表次日。行程号可跨家庭共用，个人身份为户号内角色。frame.weight 为抽样扩权数，受保护标记由调查事先约定。集中办理同办许可、代办资格和供居民使用的车次独立于主观日记。transport 的 outbound 和 return 均按发车、到达排列；可到场时段、需陪同的家庭以及业务办理时长由调查和排班资料给出。

## 运行

使用 Python 3.11，无需第三方依赖或服务。`python3 inspect_samples.py` 逐个读取资料并列出记录数；`python3 -m unittest -v` 检查关键原始记录间的关系。输出只描述原始资料，不是业务比较结果。
